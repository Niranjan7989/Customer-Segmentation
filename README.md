📊 Customer Segmentation for SBI Life Insurance

🧾 Overview

This project focuses on customer segmentation using behavioral data from credit card holders, with the objective of offering targeted recommendations in the financial services domain—such as savings plans, loans, and wealth management.

🎯 Objective

To build a segmentation model that groups customers based on their usage behavior, enabling personalized financial product recommendations.

📁 Dataset

Source: Kaggle - Credit Card Dataset
Records: ~9,000 active credit card holders
Features: 18 behavioral variables at the customer level
📋 Key Attributes

CUSTID: Unique identifier for credit card holders
BALANCE: Current balance available for purchases
BALANCEFREQUENCY: Frequency of balance updates (0 to 1)
(...other features used in clustering analysis)
🧠 Techniques Used

Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Feature scaling and transformation
Dimensionality reduction (PCA)
Clustering (KMeans, Elbow Method)
Visualization of customer segments
📌 Outcomes

Identified distinct customer groups based on behavioral patterns
Built interpretable visualizations for each segment
Proposed targeted strategies for customer engagement
🛠 Tools & Libraries

Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn)
Jupyter Notebook
